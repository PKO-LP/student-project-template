# Учебный проект: приложение для заказчика

Вы — разработчик компании «MyСофт». Выберите заказчика My[название] и создайте за 6 недель небольшое приложение, которое решает одну его проблему. Работайте индивидуально; тему согласуйте с преподавателем.

**На выбор:** заявки ремонтной мастерской; запись в груминг-салон; выдача настольных игр в клубе; бронирование репетиционных комнат; учёт расходников 3D-мастерской; регистрация на экскурсии. Можно предложить свою тему. Стартовый пример — мастерская «MyМастер».

## Что сделать

1. Заполнить README: заказчик, проблема, 5–7 функций, стек, запуск и план на 6 недель.
2. Адаптировать семь шаблонов в docs/: заменить примеры и подсказки своими данными. Вести протоколы по факту встреч и отчёты каждую неделю.
3. Создать приложение с интерфейсом, локальной БД, проверкой ввода, поиском и сохранением данных. Рекомендуемый стек — Python + Tkinter + SQLite.
4. Вести задачи в Issues и GitHub Projects; использовать main и ветки feature/..., объединять изменения через pull request. Делать содержательные коммиты по мере работы.
5. Проверить основные сценарии и ошибки ввода, записать фактические результаты. Добавить скриншоты и проверить запуск по инструкции на другом компьютере.
6. Подготовить выпуск v1.0: код, документацию, демонстрационные данные без реальных персональных сведений и краткие итоги. Согласовать условия использования кода и добавить LICENSE с выбранным текстом.

**Готовый результат:** другой человек понимает назначение проекта, запускает приложение по README и выполняет заявленные сценарии; в репозитории видны задачи, ход работы и результаты проверок.

**Углубление по согласованию:** расчёт критического пути, сравнение плана и факта стоимости, освоенный объём, дополнительные диаграммы и функции. В базовую версию не включать всё сразу.

## Как использовать набор

Создайте свой репозиторий кнопкой Use this template или скопируйте содержимое шаблона в корень уже выданного репозитория студента. Папки src/ и tests/ пока пустые; .gitkeep сохраняет их в Git. Код, тесты и готовые результаты студент создаёт сам. Подсказки в квадратных скобках постепенно заменяются ответами.
